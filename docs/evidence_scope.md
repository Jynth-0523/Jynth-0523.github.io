# Evidence scope

This is a platform source release, not the separate four-algorithm paper package.

| Evidence | What it establishes | What it does not establish |
| --- | --- | --- |
| Synthetic backend and browser tests | Specific software invariants under tested fixtures | Empirical paper replication or investment accuracy |
| Stored development snapshot | Values recorded in the existing web source | A newly audited run or a final tradable model |
| Historical locked research identity | Locked window, schema, and Formal/Shadow reporting semantics | Long-run profitability |
| Earlier literature review: 72 objects / 68 unique primary versions | Coverage of the reviewed literature corpus | 68 or 72 successful replications |
| Source and release SHA-256 inventory | File identity and the scope of publication changes | Truth of external data or statistical claims |

Successfully replicated publication count: **not established for this platform**.
Aggregate replication accuracy: **not measured**.

A future defensible replication benchmark would identify each paper and target
table, version the authorized input data and code, preregister numerical tolerances,
report all attempts and exclusions, and preserve independent comparison results.
Any accuracy statistic would then state its numerator, denominator, tolerance,
coverage, and unsuccessful cases. No such percentage is invented for this release.

Translation changes display messages and the constrained AI prompt language.
Deterministic output contracts remain tested; behavior of a live language model
under the translated prompt has not been evaluated in this release.
